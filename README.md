# Positive Even or Odd Checker (Nested If-Else in C++)

## 📌 Description
This program uses nested if-else statements to determine whether a number is positive even, positive odd, or not positive.

## 🚀 How It Works
1. User enters a number.
2. Program first checks if the number is positive.
3. If positive:
   - Check whether it is even or odd.
4. If not positive:
   - Display "Not Positive".

## 📥 Input Example

```text
8
```

## 📤 Output Example

```text
Positive Even
```

## 🛠️ Concepts Used
- C++
- Nested If-Else
- Input/Output (cin, cout)
- Modulus Operator (%)

## 🎯 Learning Outcome
- Understanding nested conditions
- Decision making in C++
- Checking number properties
